## 使用方法（PiliPlus）

PiliPlus 是一款使用 Flutter 开发的 BiliBili 第三方客户端。

1. 打开 PiliPlus，进入**主页**
2. 点击右下角**我的**
3. 点击右上角**设置**图标
4. 找到**推荐流设置**
5. 在推荐流设置中分别配置：
   - **标题关键词过滤**：将 `title_keyword_filter.txt` 中的内容复制粘贴进去
   - **APP推荐/热门/排行榜视频分区关键词过滤**：将 `video_category_filter.txt` 中的内容复制粘贴进去

关键词之间用 `|` 分隔，PiliPlus 会自动识别并过滤匹配的内容。
